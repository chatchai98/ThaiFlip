Single-tap tests cover release-only triggering, repeat, chords, focus changes, interruption, disabled targets, invalid shortcuts, capture, INI roundtrip, and native Settings persistence without rerecording. Existing conversion, leading-mark RichEdit, exclusions, popup and temporary-registry tests also passed.
Hint inspection now uses its own COM/UI Automation instance and thread, so hint reads and hint dictionary checks no longer occupy the correction queue. No app-specific latency improvement has yet been measured; slow UI Automation in the target application or an in-progress Auto request can still delay a manual correction.
Registry tests use unique temporary HKCU Software\TabThaiStartupTest-* keys and do not modify the real Windows Run key. Legacy Startup value and single-instance mutex are retained.
Physical-key Notepad correction, Alt+Tab behavior in real applications, and actual Windows logon/startup still require manual verification.
